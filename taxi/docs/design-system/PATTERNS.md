# Patterns

Паттерн — повторяющееся сочетание компонентов, решающее типовую задачу. В отличие от компонента, паттерн не всегда существует как отдельный модуль; часть описанного ниже воспроизводится вручную в нескольких местах.

## Статус заказа

**Задача.** Показать текущее состояние заказа так, чтобы оно считывалось за доли секунды.

**Решение.** Цветовая метка плюс обязательная текстовая подпись. Цвета — из `orderStatusColor`, отдельных токенов, не связанных с `danger` / `success`.

```tsx
import { orderStatusColor } from 'styles/tokens'
```

| Состояние | Токен | Значение |
|---|---|---|
| Ожидание | `orderStatusColor.waiting` | `#FFD12E` |
| Принят | `orderStatusColor.accepted` | `#00A72F` |
| Нейтральное | `orderStatusColor.neutral` | `#FFFFFF` |

**Правила.**

- Цвет никогда не единственный носитель смысла — рядом всегда текст. Эти токены имеют роль `fill` и не проходят 3:1 как самостоятельные индикаторы.
- Статусы не сливаются с семантическими цветами, даже если оттенок похож. «Принят» — не то же самое, что «успех».
- Набирать текст поверх заливки статуса можно только парными `-text` вариантами.

## Карточка заказа

**Где.** `MiniOrder`, `MiniOrders`, `Card/OrderCard`.

**Состав.** Идентификатор (`OrderId` с `variant="short"`), класс авто (`CarClassBadge`), маршрут, цена, статус, действия.

**Правила.**

- Идентификатор выводится только через `OrderId` — формат короткого суффикса един по всему приложению.
- Рамка карточки отражает статус, фон остаётся нейтральным. Заливать всю карточку цветом статуса нельзя: теряется читаемость текста.
- Радиус `--r-md`, тень `--sh-md` когда карточка лежит поверх карты, иначе граница `--c-border` без тени.
- Лента карточек скроллится горизонтально со `scroll-snap`.

## Модальное окно

**Где.** `modals/Modal.tsx` как база, `ModalStack.tsx` для стека, 24 доменные модалки.

**Слои.** Затемнение `--z-overlay`, окно `--z-modal`. Нарушать порядок нельзя: стек рассчитывает на эти значения.

**Правила.**

- Радиус `--r-lg`, тень `--sh-lg`, появление за `--d-slow`.
- Заголовок использует fluid-типографику: `clamp(var(--fs-xl), 3vw, var(--fs-xxl))`.
- Подтверждение опасного действия — основная кнопка нейтральная, опасное действие вторичной кнопкой с `--c-danger`. Обратный порядок повышает частоту случайных подтверждений.
- Модалка закрывается по затемнению и по Escape, кроме окон, требующих явного выбора.

**Известное расхождение.** В `App.scss` глобально переопределён `.MuiPaper-root` через `!important`, что задевает все компоненты MUI, использующие `Paper`. Задача `UIKIT-MUI`.

## Карта с несколькими водителями

**Где.** `components/Map`, `pages/Driver/Map`.

**Задача.** Показать маршруты нескольких водителей одновременно так, чтобы они различались.

**Решение.** Качественные палитры `categorical.driverRoute` (11 цветов) и `categorical.mapRoute` (8). Цвет назначается по индексу.

**Правила.**

- Порядок цветов в массиве значим — индекс привязан к конкретному водителю. Не сортировать, не вставлять цвета в середину.
- Не заменять на семантические токены. Схлопывание `#7C3AED → --c-info` математически корректно и функционально разрушительно.
- Маркеры точек — из `mapColor`: подача, назначение, водитель, активный маршрут, обводка.
- Цвета задаются литералами, а не `var()`: Leaflet выставляет их из JavaScript.

**Проверка.** Открыть заказ с несколькими водителями. Если два маршрута выглядят одинаково — это регрессия.

## Форма и валидация

**Где.** `Input`, `PriceInput`, `LocationInput`, `JSONForm`, `RadioCheckbox`.

**Правила.**

- Граница поля в покое `--c-border`, в фокусе — акцент, при ошибке `--c-danger`.
- Текст ошибки обязателен. Красной рамки недостаточно: это нарушение 1.4.1.
- Подсказки адресов различаются по источнику (`ESuggestionType`) и имеют визуальное отличие, а не только порядок.
- Высота поля задаётся переменной `Input.$height`, а не произвольным значением.

## Уведомления

**Где.** `Alert`, `OrderModeToast`, `MessageModal`.

Четыре уровня: `alertColor.error`, `.warning`, `.success`, `.info`. Слой `--z-toast` — выше модалок: уведомление о разрыве связи должно быть видно поверх открытого окна.

Уровень передаётся иконкой и текстом, не только цветом.

## Загрузка и пустое состояние

**Где.** `LoadFrame`, `ErrorBlock`, `loader`.

**Правила.**

- Загрузка не сбрасывает уже показанные данные: подгрузка поверх, а не мигание пустотой.
- Ошибка объясняет, что произошло, и предлагает действие. «Что-то пошло не так» без действия — не пустое состояние, а тупик.
- Скелетоны используют `--c-surface-subtle`, анимация уважает `prefers-reduced-motion`.

## Антипаттерны

| Чего не делать | Почему |
|---|---|
| Брать примитив `--p-*` в компоненте | ломает независимость правок; поймает линтер |
| Сырой `<button>` | теряются состояния, фокус и единообразие |
| Передавать смысл только цветом | нарушение WCAG 1.4.1 и плохо читается на солнце |
| Своё значение вместо шкалы | возвращает проект к 244 цветам; поймает линтер |
| Сырой `@media` | обходит шкалу брейкпоинтов; поймает линтер |
| Схлопывать палитру маршрутов | разрушает различимость на карте |
