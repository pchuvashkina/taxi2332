# Разрешённые исключения

`.stylelintrc.json` и `scripts/check-tokens.mjs` намеренно пропускают:

## Значения

| Значение | Где | Почему |
|---|---|---|
| `0` | любое свойство | отсутствие величины, шага шкалы не требует |
| проценты (`50%`, `100%`) | `border-radius`, `gap` | относительная величина, а не шаг шкалы |
| `inherit`, `auto`, `unset`, `initial` | любое свойство, включая shorthand `font` | ключевые слова CSS |
| `z-index: 0` и отрицательные | любое | вывод из потока слоёв, а не слой |
| `vw`/`vh` внутри `clamp()` | `font-size` | средний член fluid-типографики; крайние значения обязаны быть токенами |
| `rgba(...)` | тени, оверлеи | прозрачность поверх произвольного фона, цветовой токен не применим |
| `@media` с маркером `// bp-exception:` | SCSS | порог вне шкалы, помечен явно — 26 мест, задача UIKIT-BP |

## Файлы

| Файл | Почему |
|---|---|
| `src/styles/_tokens.scss`, `tokens.ts`, `tokens.json` | определение токенов |
| `src/styles/_breakpoints.scss` | определение шкалы брейкпоинтов |
| `src/lib/**` | вендорный код |

### `src/siteConstants.ts` — config exception

```ts
PALETTE: '#A90000;#ffc837',
```

Это **конфигурация тенанта**, а не стилизация UI: значение по умолчанию для переменной окружения, которая у каждого заказчика своя. Цвет приходит снаружи и попадает в `--theme--primary*` / `--theme--secondary*` через компонент `Theme` — минуя кит **по замыслу**, потому что кит описывает постоянные значения, а это переменная развёртывания.

Файл внесён в `CONFIG_EXCEPTIONS` в `scripts/check-tokens.mjs`. Если в него когда-нибудь начнут класть цвета конкретных элементов интерфейса — исключение надо снимать, а цвета переносить в `tokens.json`.

## Technical exception в TS/TSX

Сырое значение шкалы в inline-стиле допустимо, если рядом стоит маркер:

```tsx
// technical-exception: высота задаётся в px, чтобы совпасть с lineHeight
<div style={{ lineHeight: '60px' }} />
```

Без маркера guard падает с правилом `raw-scale-in-code`. Маркер ищется на самой строке или на предыдущей.

## Что остаётся обходом системы, а не исключением

`colorRaw` и `mapColor` из `src/styles/tokens.ts` отдают литералы вместо `var()`. Это нужно там, где CSS-переменная не резолвится: Leaflet задаёт цвета из JS, canvas не понимает `var()`. Места перечислены в `docs/UI_KIT.md` и проверяются глазами при приёмке — автоматика не отличит их от обхода.
